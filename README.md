# OO 학원 평가 도우미

영어 시험 문제지, 학생 OMR 응답, 정답·배점표를 이용해 자동 채점하고 결과를 분석하는 Streamlit 앱입니다. 결과는 Excel로 다운로드할 수 있으며, 채점 결과에 관한 질문과 최다 오답 유형의 유사문항 생성을 지원합니다.

## 주요 기능

- **홈 페이지**: 가천대학교 로고, 서비스 소개, 성적 분석 페이지 이동 버튼
- **성적 분석 페이지**: 문제 PDF, OMR 응답 파일, 정답·배점 PDF 업로드 및 자동 채점
- **정답표 추출**: 정답과 배점은 업로드한 PDF에서 읽으며 코드나 사전 제작 파일에 고정하지 않음
- **분석**: 반 평균·중앙값·표준편차·최고점·최저점, 문항별 정답률과 오답 수, 학생별 점수와 정오
- **Excel 다운로드**: `반 통계` 시트에 반 요약과 학생별 점수·문항 정오표를 연이어 표시하고, `학생별 결과`, `문항별 통계`, `응답 원본` 시트도 제공
- **채팅**: 인사와 기능 안내, 학생별 이름·점수·문항 결과 질문, 최다 오답 유형 유사문항 생성
- **범위 제한**: 시험 결과와 앱 사용 안내를 벗어난 질문은 정중히 안내
- **인젝션 방어**: 인젝션 검사를 도움말·결과 처리보다 먼저 적용

## 채팅 예시

- “안녕하세요.” → 인사 응답
- “안녕하세요. 어떤 기능이 지원되나요?” → 업로드, 채점, 분석, Excel, 유사문항 기능 안내
- “평균 점수와 중앙값은?” → 채점 결과 통계 안내
- “가장 성적이 저조한 학생은 누구야?” → 결과표에서 학생 이름과 점수를 조회
- “909학생이 틀린 문항은?” → 해당 학생의 오답 문항 안내
- “가장 많이 틀린 유형으로 문제를 만들어줘.” → 문제 PDF에서 근거를 찾아 유사문항 생성

결과 질문과 유사문항 요청은 세 입력 파일을 올리고 채점을 완료한 뒤 사용할 수 있습니다. 기능 안내와 인사는 채점 전에도 이용할 수 있습니다.

## 로컬 실행

Python 3.11 이상을 권장합니다. 아래 명령은 저장소 루트, 즉 `app.py`가 있는 폴더에서 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

저장소 루트의 `.env` 파일에 OpenAI 키를 설정합니다.

```dotenv
OPENAI_API_KEY="실제_API_키"
```

`.env`는 `.gitignore`에 포함되어 있으므로 저장소에 커밋하지 마세요. 기본 모델은 `gpt-6.1-sol`이며, `OPENAI_MODEL` 환경 변수 또는 Streamlit Secrets에서 바꿀 수 있습니다. 통계와 기본 학생별 응답, 인사·도움말은 코드에서 처리하고, 유사문항 생성과 자연어 통계 설명에는 API 키가 필요합니다.

## 입력 파일

1. **문제 PDF**: 문항 본문을 텍스트로 읽을 수 있는 PDF를 사용하세요. 이미지 스캔 PDF는 현재 문항 추출을 지원하지 않습니다.
2. **OMR 응답**: XLSX, XLS 또는 CSV. 첫 번째 열은 학생 이름(`학생명`, `이름` 등), 문항 열은 `Q01`, `Q02` 또는 `1`, `2` 형식으로 지정합니다. 답은 1~5 또는 ①~⑤를 지원합니다.
3. **정답·배점 PDF**: 문항 번호, ①~⑤ 정답, 배점이 텍스트로 추출되는 PDF를 사용하세요. 정답표를 충분히 읽지 못하면 채점을 중단하고 오류를 표시합니다.

## Streamlit Community Cloud 배포

1. 이 저장소를 GitHub에 올리고 Streamlit Community Cloud에서 저장소와 브랜치를 선택합니다.
2. 메인 파일 경로를 `app.py`로 지정합니다. 의존성은 저장소의 `requirements.txt`에서 설치됩니다.
3. 앱 설정의 **Secrets**에 다음 값을 추가합니다.

   ```toml
   OPENAI_API_KEY = "실제_API_키"
   OPENAI_MODEL = "gpt-6.1-sol"
   ```

4. 배포된 앱의 성적 분석 페이지에서 세 파일을 올려 채점합니다.

## 세션과 데이터 처리

대화 내용과 채점 결과는 Streamlit 세션에 유지되며 앱을 재시작하면 초기화됩니다. 별도 데이터베이스에는 저장하지 않습니다. 학생별 이름과 점수 질문은 업로드한 채점 결과에서 직접 조회하며, 유사문항 생성이나 모델 기반 자연어 설명을 요청하면 관련 질문과 필요한 결과 요약이 OpenAI API로 전달됩니다.
